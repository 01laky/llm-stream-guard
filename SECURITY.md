# Security Policy

## Supported versions

| Version | Supported        |
| ------- | ---------------- |
| 0.8.x   | Yes              |
| < 0.8   | Best effort only |

## Reporting a vulnerability

**Do not** open public GitHub issues for confirmed secret-redaction bypasses or tool-policy bypasses with live credentials.

Follow [docs/security-reporting.md](docs/security-reporting.md): minimal repro policy, sanitized input fixture, expected vs actual output, package version.

## Response

Maintainer triage via GitHub issues or the email in `package.json` `author`. No SLA guaranteed in 0.8.x.
